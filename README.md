# 电场沙盘 · FIELD SANDBOX

**大物下 VIBE · EP01《库仑定律与电场叠加》互动玩具**

拖两个电荷到任意位置，实时看中点箭头合成，亲手把场强调成零。

## 玩法

- **自由沙盘**：拖动电荷随便摆；点选后可反号 / q↔2q / 删除；加 + / 加 − / 重置（上限 8 个）。恰有 2 个电荷时显示中点 P 的 E₁/E₂ 分量箭头、红色合矢量与 |E|/E₀ 读数。默认摆好的 +q/−q 偶极中点读数恰为 **2.00**——正是片尾题的答案 B。
- **流动场线**：背景从每个正电荷按角度均匀发射场线（条数 ∝ |q|，密度诚实），沿 E 方向积分、遇负电荷/出界停止；无正电荷时从负电荷逆向追踪。细线半透明，沿线有随时间流动的亮段（速度随局部 |E| 微调）。电荷不动时路径缓存，仅拖拽/增删/resize/切模式重算，流动只推进相位。
- **发射电子**：底栏「发射电子」进入发射态后点击画布，放一个负试验电荷：逆 E 方向运动、带青色拖尾，撞到电荷或出界即消失。纯视觉粒子，不参与场源、不影响挑战判定与自由模式存档。
- **挑战模式**：P 固定在画面中心，把两个 +q 拖到让 P 点场强为零的位置，保持 1.2 秒即盖章「调零成功」。
  - 基础解：两个等量同号电荷**关于 P 镜像对称**（等距反向，矢量相消）。
  - 进阶（+q 与 +2q）：P 在连线上，距 +q 为 r、距 +2q 为 **√2·r**——(√2r)² = 2r² 恰好抵消 2 倍电量，平方反比的手感。
  - 手机上容差只有约 1 像素，所以挑战模式带**磁吸**：拖到精确解附近 16px 内自动钉住（金色脉冲提示）；「提示」按钮显示幽灵解点。放得离 P 远一点场更弱、更容易调零——这本身就是 1/r²。
- **截图**：底栏「截图」导出带角标与读数的 PNG。手机/B站内置浏览器弹全屏图，**长按保存**；桌面直接下载。
- 键盘：点选后方向键微移（Shift 加速）、Delete 删除、Esc 取消。布局与挑战最佳成绩自动保存在本机浏览器。

## 物理说明

E(P) = Σ qᵢ·dᵢ/|dᵢ|³（取 k=1，电量以 q₀ 为单位，距离以 d₀ = 0.22×短边 为单位）；读数 |E|/E₀，E₀ = 1/d₀²。场强是**矢量和**，不是数字相加。奇点附近做截断保护，读数上限显示 99.99+。

**全部画面为示意**，公式适用于真空中点电荷（理想模型）。出处见 EP01 交付文档 facts.md（Coulomb 1785 / Cavendish 1773·1879 / Williams–Faller–Hill PRL 26,721 (1971) / Griffiths《Introduction to Electrodynamics》ch.2）。

## 技术

单文件 `index.html`，零依赖、零外部请求（<40KB），Canvas 2D + Pointer Events，手机/桌面/横竖屏全适配。直接双击打开即玩；**在 B站/App 内置浏览器打开时，建议点右上角「用系统浏览器打开」**以获得完整体验（截图保存、本地存档）。页面可自由镜像。

自检：`python tests/test_sandbox.py`（需 playwright + Chromium），覆盖物理读数、真实鼠标/触摸拖拽、挑战判定（滞回/磁吸/进阶）、横竖屏旋转、持久化、4× CPU 节流性能与截图双路径；另含流动场线（空闲缓存/拖拽重算）、发射电子（逆场运动/不扰判定/撞电荷消失）与节流下 fps≥30 断言。
